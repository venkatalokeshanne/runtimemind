# Coding Interview: System Design Round

How to navigate the interview when asked to design a service.

## Steps
1) Clarify use-cases and constraints
2) Define API surface and data model
3) Sketch high-level architecture
4) Deep-dive: data, scaling, consistency
5) Bottlenecks & mitigations
6) Trade-offs and alternatives

## Artifacts to mention
- SLAs/SLOs and guardrails
- Back-of-the-envelope capacity math
- Read/write paths
- Storage and cache choices
- Failure handling and retries

## Common pitfalls
- Over-indexing on tech names vs constraints
- Skipping data model
- Ignoring backpressure and queues
